# MaquetacionAbsolute

Práctica de desarrollo web realizada durante mi formación en Desarrollo de Aplicaciones Multiplataforma (DAM).

## Descripción

Proyecto de maquetación de una página web utilizando HTML y CSS, centrado en el posicionamiento absoluto de los elementos.

## Tecnologías utilizadas

- HTML5
- CSS3

## Conceptos trabajados

- Estructura de documentos HTML.
- Hojas de estilo CSS.
- Posicionamiento absoluto (`position: absolute`).
- Uso de las propiedades `top`, `left`, `right` y `bottom`.
- Organización y distribución de elementos en una página web.

## Estructura del proyecto

- `index.html`: estructura y contenido de la página.
- `css/styles.css`: estilos y posicionamiento de los elementos.

## Objetivo

Practicar la maquetación web mediante CSS y comprender cómo posicionar elementos de forma precisa utilizando el posicionamiento absoluto.
